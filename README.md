# Procrastination Behaviour Analysis

An observational data analysis project exploring my procrastination
patterns using **R**, **tidyverse**, and **ggplot2**.

## Overview

For this project, I collected my own observational data about
procrastination episodes. Each observation recorded the task I was
avoiding, how long I procrastinated, what I did instead, and my stress
level.

The goal was to turn everyday behavioural data into a reproducible
analysis and identify patterns in when and how procrastination occurred.

## Key Questions

-   Which distractions occurred most frequently?
-   On which days did procrastination occur most often?
-   How long did procrastination episodes typically last?
-   Which tasks and activities were associated with procrastination?

## Visualisations

The analysis includes visualisations of:

-   distraction types
-   procrastination episodes by day
-   distribution of procrastination duration
-   tasks avoided and activities completed instead

## Key Findings

-   **Social media** was the most common distraction.
-   The number of procrastination episodes varied noticeably across
    days.
-   Most procrastination episodes were concentrated around moderate
    durations, with a smaller number of longer episodes.
-   Talking, watching videos, and resting were also recurring
    distractions.
